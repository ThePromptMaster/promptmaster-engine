# Record 1: Firm Finalist Checklist Template (FIRM-01)

**Purpose:** A reusable checklist for any retained search. Copy one finalist block per finalist. Fill each field from that engagement's own source IDs.

**Each engagement sets its own terms (FIRM-01).** This template does not set who calls references, how many calls are made, or what goes to the client. Those answers come only from the engagement's terms.

## Finalist block

Copy this block once per finalist. Always write the finalist's full name.

**Finalist (full name):**

| Field | Entry | Source ID |
|---|---|---|
| Who contacts references | *State who makes reference contact under this engagement's terms.* | |
| What the consultant sends to the client | *State exactly what goes to the client. If the terms restrict anything, state what is never sent.* | |
| Next action | *State the single next step for this finalist.* | |

**Current position (supporting line):** *State what has and has not been done. Do not record a step as done until it is done.*

## History log

Record only completed actions, on the date they were done. A planned or ready step stays in **Next action** until it is done. If a source gives no date, write "Date not recorded."

| Date | Finalist (full name) | Action completed | Source ID |
|---|---|---|---|
| | | | |

**Rules for keeping the log:**

- Never edit or delete an earlier entry.
- If an entry was wrong, keep it and add a dated **Correction** entry.
- If a client term is replaced, add a **Superseded** entry stating what replaced it and when.
